# Clutter and fixes — a lookup list

A working reference for the editing passes in SKILL.md. Use it to catch the common offenders systematically. None of these are absolute rules; they're defaults you override when the context calls for it. The point is always the same: fewer words, plainer words, stronger verbs, the writer's meaning intact.

## 1. Bloated phrases → short equivalents
- at this point in time → now
- at the present time → now
- in the near future → soon
- in the event that → if
- in order to → to
- for the purpose of → to / for
- due to the fact that / owing to the fact that → because
- in spite of the fact that → although
- with regard to / with respect to / in terms of → about (or recast)
- in the process of → (usually delete)
- a large number of → many
- a small number of → a few
- the majority of → most
- a sufficient amount of → enough
- has the ability to / is able to → can
- has the opportunity to → can
- is in a position to → can
- make a decision → decide
- make an adjustment → adjust
- give consideration to → consider
- come to the realization that → realize
- on a daily basis → daily
- in a timely manner → promptly / on time
- until such time as → until
- in the vicinity of → near / about
- a percentage of → some

## 2. Pompous / jargon words → plain words
- utilize → use
- facilitate → help / ease
- implement → carry out / do
- commence / initiate → begin / start
- terminate → end / stop
- endeavor → try
- ascertain → find out
- demonstrate → show
- purchase → buy
- obtain → get
- require → need
- sufficient → enough
- additional → more / extra
- approximately → about
- numerous → many
- individuals → people
- prior to → before
- subsequent to → after
- currently / presently → now (or delete)
- assist → help
- indicate → show / say
- request → ask
- possess → have
- reside → live
- inquire → ask
- component → part
- methodology → method
- functionality → features / what it does
- leverage (as verb) → use
- impactful → (recast: "has a strong effect," or name the effect)
- operationalize → put into practice
- optimal → best

## 3. Padding and throat-clearing to delete
Usually the whole phrase can go with no loss:
- the fact that
- it should be noted / pointed out that
- it is important to note that
- it is interesting to note that
- needless to say
- for all intents and purposes
- in a very real sense
- when all is said and done
- at the end of the day
- as a matter of fact
- I would argue that / I would say that
- in my opinion, I think that (pick one, not both)
- basically / essentially / actually / literally (when not literal)
- as you may or may not know
- suffice it to say

## 4. Redundant pairs (cut one half)
The italicized part is already contained in the other word:
- *personal* friend
- *free* gift
- *end* result
- *final* outcome
- *future* plans
- *past* history / *past* experience
- *advance* planning / *advance* warning
- *close* proximity
- *completely* eliminate / *totally* destroy
- *various* different
- *unexpected* surprise
- *added* bonus
- *joint* collaboration / collaborate *together*
- *brief* summary
- *new* innovation
- *each and every*
- *first and foremost*
- *ways and means*
- *few and far between*
- *actual* fact / *true* fact
- *general* consensus
- *sudden* impulse
- ATM *machine* / PIN *number* (the last letter already says it)

## 5. Qualifiers and hedges to prune
Delete on sight unless they carry real, needed precision:
very, really, quite, rather, somewhat, pretty (much), fairly, a bit, a little, sort of, kind of, in a sense, in a way, more or less, to some extent, basically, essentially, actually, literally, just, simply, totally, definitely, certainly, arguably, perhaps possibly (stacked hedges), I think / I feel / I believe (when the whole piece is already your view).

"Very unique," "quite perfect," "rather essential" are worse than clutter — the base word is already absolute, so the qualifier is wrong as well as weak.

## 6. Weak verb + noun → strong verb
Watch for "make / do / have / give / conduct / perform / provide + a noun" where a single verb hides inside the noun:
- make a decision → decide
- make a recommendation → recommend
- reach an agreement → agree
- conduct an investigation → investigate
- perform an analysis → analyze
- give an explanation → explain
- provide assistance → help
- have a discussion → discuss
- take into consideration → consider
- come to a conclusion → conclude
- put emphasis on → emphasize
- is reflective of → reflects
- is indicative of → indicates
- has a preference for → prefers

## 7. "There is / it is" rewrites
Find the real subject and let it act:
- "There are many people who believe…" → "Many people believe…"
- "There is a need for us to decide." → "We need to decide."
- "It is my belief that…" → "I believe…"
- "It is often the case that prices rise." → "Prices often rise."
- "There was a large crowd that gathered." → "A large crowd gathered."

## 8. Adverbs that duplicate the verb
The verb already contains the adverb — cut it, or pick a verb that needs no help:
- shouted loudly, whispered softly, gripped tightly, clenched tightly
- smiled happily, cried sadly, rushed hurriedly, sprinted quickly
- added an additional, blended together, joined together, gathered together
- completely finished, totally destroyed, fully complete
- circled around, descended down, rose up, reverted back, returned back
- nodded his head, shrugged his shoulders, blinked his eyes (what else would he nod?)

## 9. Small mechanics worth watching
- **that vs. which:** use *that* for restrictive clauses (no comma) — "the report that we filed"; use *which* for nonrestrictive asides (with commas) — "the report, which we filed late, …". When "which" isn't setting off an aside, it's usually a wordier "that."
- **Exclamation points:** let the sentence carry the emphasis. One is plenty; a page of them means none land.
- **The period is your friend:** most writers don't stop soon enough. When a sentence gets tangled, the cure is often a period, not a comma.
- **Contractions:** fine and usually warmer in most registers — "don't," "it's," "you're." Drop them only for formal or ceremonial tone.
- **Paragraphs:** keep them reasonably short; a wall of text pushes readers away, and a paragraph break gives the eye a rest and the argument a joint.
- **Mood-changers up front:** put "but," "yet," "so," "still," "instead," "meanwhile" at the *start* of the sentence they turn — the reader learns the direction of the turn before wading in, not after.
- **Concept-noun pileups:** sentences built entirely of abstract nouns ("the implementation of the optimization of the utilization…") lose all traction. Find the human and the verb underneath and rebuild around them.
